# 开发与打包说明

技术栈：Electron 44.7.0、TypeScript/JavaScript、Node.js SQLite。依赖版本以 electron/pnpm-lock.yaml 为准。

在项目根目录运行：

```powershell
pnpm run deps:install
pnpm start
pnpm run build
pnpm test
pnpm run package
```

源码位于 electron/src/ 与 electron/ui/，测试位于 tests/，编译输出位于 electron/dist/。打包输出为 artifacts/QingRead-Electron/win-unpacked/，须整体分发。打包前从托盘退出正在运行的软件。

默认不生成压缩包。Windows 是当前交付平台，其他平台需要单独构建和实机验证。
